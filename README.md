# Onboarding WBG Pioneers · Equipe Governança

Painel estático (um único `index.html`, sem dependências externas). Para publicar no GitHub Pages:

1. Crie um repositório e envie o conteúdo desta pasta para a raiz (ou para `/docs`).
2. Em Settings → Pages, escolha a branch (e a pasta raiz ou `/docs`).
3. A página fica em `https://<usuario>.github.io/<repositorio>/`.

Arquivos: `index.html`, `capa_wbg.mp4` (capa), `foto-*.jpg` (fotos de Brasília), `flags/*.png` (bandeiras dos estados e do Reino Unido).
As marcações feitas na página (distribuição de trabalho, metas, decisões, simulador) ficam salvas só no navegador de quem abre (localStorage).

Créditos: mapa do Brasil a partir de svg-maps (CC BY 4.0); bandeiras a partir de SVGs oficiais via br-state-flags (MIT).
